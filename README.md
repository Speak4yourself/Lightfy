# Lightfy

A slim Spotify player for Windows, written in Rust. It uses a few MB of memory instead of a few hundred.

This repository holds Lightfy's releases. Installed copies check the latest release and offer to install a newer one.

## Using it
- You need Windows 10 or 11 (64-bit) and Spotify Premium.
- Download `Lightfy.exe` from the latest release and run it.
- Lightfy walks you through setup:
  1. Sign in to your own Spotify account.
  2. Make your own Soloist key.
  3. Lightfy downloads Spotify's official player straight from Spotify.

Updates are signed. Lightfy won't install a download whose signature doesn't match.

Lightfy isn't affiliated with or endorsed by Spotify.
